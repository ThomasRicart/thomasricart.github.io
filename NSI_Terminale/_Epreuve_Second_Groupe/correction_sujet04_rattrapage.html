    Corrigé — Épreuve du second groupe, Sujet 04 — Session 2026

    Exercice 1 — Fusionner deux dictionnaires

    def ajoute_dictionnaires(d1, d2):
    ''' Renvoie un dictionnaire d dont les clés sont celles de d1
    et celles de d2 réunies, et dont les valeurs sont la somme des
    valeurs associées à chaque clé dans d1 et d2.
    Si une clé n'est présente que dans un des deux dictionnaires,
    sa valeur associée dans le dictionnaire d est la même que
    sa valeur dans le dictionnaire où elle est présente. '''
    d = {}
    for cle in d1:
        d[cle] = d1[cle]
    for cle in d2:
        if cle in d:
            d[cle] = d[cle] + d2[cle]
        else:
            d[cle] = d2[cle]
    return d

assert ajoute_dictionnaires({1: 5, 2: 7}, {2: 9, 3: 11}) == {1: 5, 2: 16, 3: 11}
assert ajoute_dictionnaires({}, {2: 9, 3: 11}) == {2: 9, 3: 11}
assert ajoute_dictionnaires({1: 5, 2: 7}, {}) == {1: 5, 2: 7}

    Logique : on recopie d'abord toutes les clés de d1 dans d, puis on parcourt d2 : si la clé existe déjà (donc venait de d1), on ajoute la valeur de d2 ; sinon, on la crée directement avec la valeur de d2.

    Exercice 2 — Graphe de routeurs

    Graphe (d'après la figure)

            C
       / \
      A   D --- F
     /|\   \
    B | E---'
      (A-E)

    Pour plus de clarté, les liaisons (arêtes) du graphe sont : A–B, A–C, A–E, C–D, E–D, D–F

    Question 1 — Parcours en largeur (BFS) depuis A

    On explore les voisins dans l'ordre alphabétique, niveau par niveau :

    • Niveau 0 : A
    • Niveau 1 (voisins de A, par ordre alphabétique) : B, C, E
    • Niveau 2 : en traitant B (rien de nouveau), puis C (voisin D, nouveau), puis E (voisin D, déjà découvert) → D
    • Niveau 3 : en traitant D, voisin F, nouveau → F

    → Ordre de parcours : A, B, C, E, D, F

    Question 2 — Table de routage de A (protocole RIP)

    Le nombre de sauts correspond au niveau atteint lors du parcours en largeur. Pour D, deux chemins de longueur égale existent (A→C→D et A→E→D) ; comme C est découvert avant E dans l'ordre du parcours, le chemin par C est retenu en premier, et F (accessible uniquement via D) hérite du même prochain routeur que D.

    routeur nombre de sauts prochain routeur
    B 1 B
    C 1 C
    D 2 C
    E 1 E
    F 3 C

    Question 3 — Méthode relie

    class Routeur:
    def __init__(self, nom):
        self.nom = nom
        self.voisins = []

    def relie(self, autre_routeur):
        ''' Relie ce routeur à autre_routeur (relation symétrique).
        Ne fait rien si la liaison existe déjà. '''
        if autre_routeur not in self.voisins:
            self.voisins.append(autre_routeur)
        if self not in autre_routeur.voisins:
            autre_routeur.voisins.append(self)

    Remarque : une liaison réseau est symétrique (si A est relié à B, B est relié à A) — il faut donc mettre à jour les deux listes voisins, tout en vérifiant que la liaison n'existe pas déjà pour éviter les doublons.

    Question 4 — Création des routeurs

    A = Routeur('A')
B = Routeur('B')
C = Routeur('C')
D = Routeur('D')
E = Routeur('E')
F = Routeur('F')

    Question 5 — Connexion des routeurs selon le graphe

    A.relie(B)
A.relie(C)
A.relie(E)
C.relie(D)
E.relie(D)
D.relie(F)

    Exercice 3 — Suite de Fibonacci récursive

    def fibo(n):
    ''' Renvoie le n-ième terme de la suite de Fibonacci. '''
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        return fibo(n - 1) + fibo(n - 2)

assert fibo(0) == 0
assert fibo(1) == 1
assert fibo(7) == 13

    Vérification : la suite vaut 0, 1, 1, 2, 3, 5, 8, 13 pour n = 0 à 7, donc fibo(7) == 13 est bien cohérent.

    Remarques générales sur le sujet

    • L'exercice 2 est le plus riche des quatre sujets vus jusqu'à présent : il combine théorie des graphes (BFS), une application réseau concrète (calcul façon RIP du nombre de sauts) et une implémentation orientée objet complète (classe Routeur, méthode relie symétrique). C'est une bonne synthèse de plusieurs items du programme dans un seul exercice.
    • Avec 5 sous-questions qui s'enchaînent, l'exercice 2 est dense pour un oral de 20 minutes : un candidat bloqué sur la lecture du graphe (question 1) risque de manquer de temps pour les questions 3 à 5. Cela vaut le coup de rappeler aux élèves qu'ils peuvent traiter les questions 3 et 4 (méthode relie, création des routeurs) indépendamment du résultat du parcours en largeur.
    • Le graphe propose une bonne subtilité pédagogique : deux chemins de même longueur mènent à D (via C ou via E), ce qui permet de discuter comment un protocole de routage choisit un prochain saut en cas d'égalité.
