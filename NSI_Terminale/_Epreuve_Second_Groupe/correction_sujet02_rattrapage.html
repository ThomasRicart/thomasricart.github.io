    Corrigé — Épreuve du second groupe, Sujet 02 — Session 2026

    Exercice 1 — Comptage d'occurrences dans un tableau

    def compte_occurrences(x, tab):
    ''' Compte le nombre d'occurrences de x dans tab.
    x : valeur à compter (int, float, str, etc.)
    tab : tableau de valeurs (list)
    Renvoie : le nombre d'occurrences de x dans tab (int)
    '''
    compteur = 0
    for element in tab:
        if element == x:
            compteur += 1
    return compteur

assert compte_occurrences(5, []) == 0
assert compte_occurrences(5, [-2, 3, 1, 5, 3, 7, 4]) == 1
assert compte_occurrences('a', ['a','b','c','a','d','e','a']) == 3

    Remarque : l'énoncé interdit explicitement tab.count(x) — l'objectif est de faire écrire une boucle de parcours avec un accumulateur, compétence de base attendue en NSI.

    Exercice 2 — Routage réseau (OSPF)

    Rappel du graphe (d'après le tableau des coûts)

    Liaison Coût
    R1 – R2 10
    R1 – R4 100
    R1 – R5 100
    R2 – R3 1
    R2 – R4 10
    R2 – R5 10
    R3 – R4 1
    R4 – R5 1
    R5 – R6 1

    R6 est le routeur relié à Internet.

    Question 1 — Table de routage complète de R1

    En appliquant un algorithme de plus court chemin (type Dijkstra) depuis R1, on obtient les distances suivantes :

    • R1 → R2 : 10 (liaison directe)
    • R1 → R2 → R3 : 10 + 1 = 11
    • R1 → R2 → R3 → R4 : 11 + 1 = 12 (moins cher que R1 → R4 direct à 100, ou R1 → R2 → R4 à 20)
    • R1 → R2 → R3 → R4 → R5 : 12 + 1 = 13 (moins cher que R1 → R5 direct à 100, ou R1 → R2 → R5 à 20)
    • R1 → R2 → R3 → R4 → R5 → R6 : 13 + 1 = 14

    Dans tous les cas, le chemin le moins coûteux passe systématiquement par R2 en premier saut (grâce au faible coût des liaisons R2–R3, R3–R4 et R4–R5, très inférieur aux liaisons directes R1–R4 et R1–R5 à 100).

    Table de routage de R1 :

    destination prochain saut distance
    R2 R2 10
    R3 R2 11
    R4 R2 12
    R5 R2 13
    R6 R2 14

    Question 2 — Route suivie par une requête de LAN1 vers Internet

    En suivant la table de routage ci-dessus jusqu'à R6 (point de sortie vers Internet) :

    → Route : R1 → R2 → R3 → R4 → R5 → R6 → Internet

    → Distance totale dans le maillage : 14

    Question 3 — Nouvelle route si R2 tombe en panne

    Sans R2, les liaisons R1–R2, R2–R3, R2–R4 et R2–R5 disparaissent. Il ne reste que les liaisons directes R1–R4 (100) et R1–R5 (100), ainsi que R3–R4 (1), R4–R5 (1) et R5–R6 (1).

    On compare les deux chemins possibles depuis R1 :

    • R1 → R4 → R5 → R6 : 100 + 1 + 1 = 102
    • R1 → R5 → R6 : 100 + 1 = 101

    Le chemin le plus court est désormais direct par R5 :

    → Nouvelle route : R1 → R5 → R6 → Internet

    → Nouvelle distance : 101

    Exercice 3 — Structure de pile (LIFO)

    Question 1 — Fonctionnement d'une pile

    Une pile fonctionne selon le principe « Last-In First-Out » (LIFO) : le dernier élément ajouté (empilé) est le premier élément retiré (dépilé). On ne peut ajouter ou retirer un élément qu'au sommet de la pile — contrairement à une file (FIFO) où l'on retire les éléments dans leur ordre d'arrivée.

    Question 2 — État de p1 et p2 après exécution

    Déroulé du code :

    1. p1.empiler('A') → p1 (bas→haut) : [A]
    2. p1.empiler('B') → p1 : [A, B]
    3. p1.empiler('C') → p1 : [A, B, C]
    4. p1.empiler('D') → p1 : [A, B, C, D] (D au sommet)
    5. Boucle tant que p1 n'est pas vide :
    6. depiler() retire D (sommet) → p2.empiler('D') → p2 : [D]
    7. depiler() retire C → p2.empiler('C') → p2 : [D, C]
    8. depiler() retire B → p2.empiler('B') → p2 : [D, C, B]
    9. depiler() retire A → p2.empiler('A') → p2 : [D, C, B, A]

    État final : - p1 : vide (contenu = []) - p2 : [D, C, B, A] (bas → haut), avec A au sommet

    Remarque pédagogique : transférer le contenu d'une pile vers une autre pile de cette manière inverse l'ordre des éléments. C'est le principe utilisé pour inverser une pile (ou une chaîne de caractères) à l'aide d'une pile auxiliaire.

    Question 3 — Méthode est_vide

    def est_vide(self):
    ''' renvoie True si la pile est vide et False sinon '''
    return self.contenu == []

    Question 4 — Méthode empiler

    def empiler(self, e):
    ''' empile un élément dans la pile '''
    self.contenu.append(e)
    self.nb_elements += 1

    Question 5 — Méthode depiler

    def depiler(self):
    ''' dépile un élément et le renvoie si la pile n'est pas vide
    Renvoie None si la pile est vide '''
    if self.est_vide():
        return None
    self.nb_elements -= 1
    return self.contenu.pop()

    Remarques générales sur le sujet

    • Sujet cohérent et bien calibré pour un oral de 20 minutes, avec trois thèmes bien distincts : algorithmique de base (tableaux), réseaux (routage OSPF / plus court chemin), structures de données (pile).
    • L'exercice 2 est particulièrement bien construit : la question 3 (panne de R2) oblige l'élève à recalculer le plus court chemin plutôt qu'à réciter un résultat appris par cœur, ce qui teste une réelle compréhension de l'algorithme.
    • Petite coquille dans l'énoncé de l'exercice 2 (« qui minimisent respectiveme la somme des coûts ») — accord et mot tronqué, sans incidence sur la résolution.
